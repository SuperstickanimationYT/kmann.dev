How these portals work

A pair of portal ends is one doorway sliced through the middle, with the two halves carried apart. Looking into one end, you see what is behind the other end because it really is right there, on the far side of the doorway.

That settles what happens when an end moves. Only movement relative to the doorway counts: an object resting in place while an end sweeps over it is, from the doorway's point of view, an object moving into it. It comes out the other end with that speed, so a falling or sliding end throws things.

An object part-way through is in both places at once. Its front half sits beyond the far end and can bump into things there, and its back half still rests on whatever is under it here.

Both ends of a pair are always the same shape. On a curved end, an object passes wherever it crosses the curve. Ring and square-frame ends connect outside to inside.

Controls
  • Grab: drag an object to carry it and let go to throw it. Drag a portal end to move it: it keeps whatever speed you give it while dragging, so sweeping an end over a resting object launches it. Drag the white knob to turn an end. Tap a portal end, wall or laser to edit it.
  • Box, Ball, Wedge: tap to drop one; drag to throw one in the direction you drag.
  • Portal: drag from where end A goes to where end B goes, or tap for a pair side by side.
  • Wall: drag to draw one. Laser: tap to place, drag to aim.
  • Each object carries a flag, so you can tell when a mirror portal has flipped it.
  • Keys: 1–7 tools, Space pause, Delete remove selected, Esc deselect.
