# Sail the Stars

The main menu offers Explore, Mission and Practice. Mission is Find Home, the game this started as; Practice is the same search with labels.

## Goal of Explore mode

A digital replica of the universe, free in the browser: real data where it exists, procedural detail where it doesn't, and the made-up parts labelled. It includes the best-known celestial objects and looks as photorealistic as possible within 30 fps at 1080p on integrated graphics and a 10 MB download.
