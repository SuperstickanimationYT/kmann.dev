Comma and period change the speed. Above 10×, each piece of the rocket coasts as one solid body, so it only works with every engine off and above the air. A program that lights an engine stops it.

Engines

    No engines yet. Pick the Engine tool and tap a beam near the end where the nozzle goes. The engine pushes toward the other end, and burns fuel from the nearest tank still attached to it.

    While flying, the throttle lever drives every engine the CPU doesn't, up to each engine's thrust limit. A and D tilt each engine's thrust across its gimbal range. Stability assist (the Assist button, or T) stops the rocket turning when you let go and holds it there with gimbals and reaction wheels. It waits while a program steers. You can still build your own gimbal from a motor instead.

    Reaction wheels

      No reaction wheels yet. Pick the Wheel tool and tap a beam. A reaction wheel twists its beam by spinning a flywheel the other way, so it steers even with the engine off, and stability assist uses it to hold still.

      A wheel stores everything it absorbs. Once full (the disc fills up) it can't twist further that way until you twist back. Fighting the air with it fills it fast.

      Motors

        No motors yet. Pick the Motor tool, tap the beam that should turn, then tap a beam joined to it at the same joint. A motor between an engine and its tank steers the thrust.

        CPU

        No CPU yet. Pick the CPU tool and tap a beam to mount one. Then write a program here that reads sensors and drives engines and motors, or load a ready-made one from the program library, such as an autopilot that flies to orbit.

        How the language works 
        # Lines starting with # are notes.
keep target = 100       # keep: set once, then remember
error = target - altitude

if error > 0 and fuel > 0 then
  engine1.throttle = clamp(error * 0.01, 0, 1)
elseif vspeed < -5 then
  engine1.throttle = 0.6
else
  engine1.throttle = 0
end

if fuel < 1 then sep1.fire = 1 end

        Math: + - * / % ^ and brackets. Compare with == != < <= > >=, combine with and, or, not. true is 1 and false is 0. Angles are in degrees.

        Rockets

        Loading or pasting replaces the rocket on the pad. Undo brings it back. Copy rocket turns the whole rocket, program included, into text you can save anywhere or send to someone.

        Building

        Parts stack in one column, bottom to top. Engines burn fuel from the nearest tank still attached to them. The capsule has a reaction wheel, so A and D turn the rocket even with the engines off. Advanced shows the beams and joints each part is made of, and lets you program the computer.

        The whole Solar System is here at 1/20 of real size and distance, with real surface gravity: the Sun, eight planets, Pluto and the main moons, all moving in their orbits. Low Earth orbit takes about 1.7 km/s, Earth's year lasts about 82 days, and every launch starts with the planets in the same places, so waiting on the pad with fast warp sets up a transfer window. Beams are rigid and pass through each other, and only joints touch the ground. Air thins out above the launch pad and is gone at 35 km. Layers only organise the build. Drag with the right mouse button or two fingers to pan, and scroll or pinch to zoom out as far as Neptune.
