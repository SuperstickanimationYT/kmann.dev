Engines

    No engines yet. Pick the Engine tool and tap a beam near the end where the nozzle goes. The engine pushes toward the other end, and burns fuel from the nearest tank still attached to it.

    Motors

      No motors yet. Pick the Motor tool, tap the beam that should turn, then tap a beam joined to it at the same joint. A motor between an engine and its tank steers the thrust.

      CPU

      No CPU yet. Pick the CPU tool and tap a beam to mount one. Then write a program here that reads sensors and drives engines and motors.

      Program

      How the language works 
      # Lines starting with # are notes.
keep target = 100       # keep: set once, then remember
error = target - altitude

if error > 0 and fuel > 0 then
  engine1.throttle = clamp(error * 0.01, 0, 1)
elseif vspeed < -5 then
  engine1.throttle = 0.6
else
  engine1.throttle = 0
end

if fuel < 1 then sep1.fire = 1 end

      Math: + - * / % ^ and brackets. Compare with == != < <= > >=, combine with and, or, not. true is 1 and false is 0. Angles are in degrees.

      Rockets

      Loading or pasting replaces the rocket on the pad. Undo brings it back. Copy rocket turns the whole rocket, program included, into text you can save anywhere or send to someone.

      Building

      Earth and the Moon are 1/20 of their real size, with real surface gravity, so low orbit takes about 1.8 km/s and one lap about 19 minutes. Beams are rigid and pass through each other, and only joints touch the ground. Air thins out above the launch pad and is gone at 35 km. Layers only organise the build. Drag with the right mouse button or two fingers to pan, and scroll or pinch to zoom all the way out to the Moon.
