Motors

    No motors yet. Pick the Motor tool, tap the beam that should turn, then tap a beam joined to it at the same joint. The motor turns the first beam against the second.

    CPU

    No CPU yet. Pick the CPU tool and tap a beam to mount one. Then write a program here that reads sensors and drives motors.

    Program

    How the language works 
    # Lines starting with # are notes.
speed = 0.5             # set a name
keep count = 0          # keep: set once, then remember
count = count + 1

if touch1 == 1 then
  motor1.power = -speed
elseif tilt > 10 and not (time < 2) then
  motor1.power = 0
else
  motor1.power = speed
end

while motor2.angle < 90 do
  motor2.power = 1      # waits here, burning clock ticks
end

    Math: + - * / % ^ and brackets. Compare with == != < <= > >=, combine with and, or, not. true is 1 and false is 0. Angles are in degrees.

    Robots

    Loading or pasting replaces the robot on the board. Undo brings it back. Copy robot turns the whole robot, program included, into text you can save anywhere or send to someone.

    Building

    Beams are rigid and pass through each other. Only joints touch the ground. Where two beams meet they pivot freely unless a motor drives them. Layers only organise the build: pick a layer number above the board to fade the rest, and new beams go on the chosen layer. A ringed joint is shared with another layer. Drag with the right mouse button or two fingers to pan, and scroll or pinch to zoom.
